# Документация

Проект: минимальный агент, который пишет код по просьбе пользователя, скил, который заставляет его уточнять важные детали вместо того, чтобы их додумывать, и система, которая измеряет, насколько скил помогает на разных моделях.

## В каком порядке читать

| Документ | Для кого | О чём |
| --- | --- | --- |
| [architecture.md](architecture.md) | для всех, читать первым | задача, основные понятия, из чего состоит система, как проходит диалог, как проводим эксперименты, принятые решения |
| [contracts.md](contracts.md) | для всех | общие классы, через которые части системы передают друг другу данные |
| [tasks.md](tasks.md) | для всех | план работы каждого по этапам |
| [orchestration.md](orchestration.md) | Сергей | агент, вызов моделей, файлы настроек, программа для ручного диалога |
| [clarification-skill.md](clarification-skill.md) | Родион | скил уточнений и симулятор пользователя |
| [evaluation.md](evaluation.md) | Егор | тест-кейсы, судья, метрики, кэш, хранение результатов |

## Структура репозитория

```
agent/                  агент, общие классы, вызов моделей, чтение конфигов, консольная программа
  prompts/base.md       базовый системный промпт
skills/
  clarification/        скил уточнений: код, текстовые правила, запросы к модели
configs/                варианты агента: bare.yaml, prompt_only.yaml, clarification.yaml
evals/
  cases/clarification/  тест-кейсы, по файлу на кейс
  run.py                runner: запускает прогоны
  user_sim.py           симулятор пользователя
  judge.py              судья
  metrics.py            подсчёт метрик
  checks.py             проверка присланного кода
  cache.py              кэш ответов модели
  EXPERIMENTS.md        журнал экспериментов
  results/  cache/      результаты и кэш, в репозиторий не попадают
tests/                  автоматические тесты
```

## Правила

- `agent/types.py` используют все, поэтому если меняешь его, предупреди остальных.
- К коду пишем тесты. Тесты не обращаются к настоящим моделям и к интернету, вместо модели используется `FakeLLM`.
- Новый скил добавляется вместе со своим конфигом и тест-кейсами.
- Если меняешь то, что описано в документации, поправь и документацию.
