# AI Agent Harness — оркестрация и API модулей

Онлайн-версия (редактируемая): https://claude.ai/artifact/DyUpMvXrGhCMWvDMf45BdK

| Файл | Для кого | Что внутри |
| --- | --- | --- |
| `01_Оркестрация.pdf` | вся команда | схема оркестрации (3 диаграммы), зоны ответственности, модели данных, внешнее API, конечный автомат, agent loop, восстановление, лимиты, план и открытые вопросы |
| `02_Запрос API Егор.pdf` | Егор | Storage + Context Engine: когда вызываются, сигнатуры, гарантии, предлагаемая схема таблиц, вопросы |
| `03_Запрос API Родион.pdf` | Родион | Clarification Engine: когда вызывается, вход/выход, что оркестратор делает с ответом, правила, пример JSON, вопросы |
| `diagrams/` | — | те же схемы отдельными картинками |

Схемы:
1. `1_последовательность_вызовов.png` — кто кого вызывает в сценарии «Проверь тесты проекта».
2. `2_входящее_сообщение.png` — куда попадает сообщение пользователя.
3. `3_главный_цикл.png` — шаг анализа и шаг выполнения.
4. `4_статусы_задачи.png` — конечный автомат статусов.

Цвета: оранжевый — модули Егора, зелёный — Родиона, синий — Сергея.
