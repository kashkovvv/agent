## Объём MVP

Сохраняем два метода Сергея: assess и parse_answers; решения ASK / PROCEED / ABORT; существующие статусы вопросов и повторный анализ после ответа. Модуль не получает собственный поиск, очередь задач или отдельное хранение состояния.

Единственное предлагаемое изменение правила API: разрешить USER в assess.resolved_slots для параметров, явно указанных в пользовательских сообщениях текущей задачи, со ссылкой в evidence. Оно требует согласования; пока не считаем его частью утверждённого контракта.

Документ с краткой позицией к встрече исключён из пакета. Расширенные граничные случаи не являются условиями готовности первой версии.
