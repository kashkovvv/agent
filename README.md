# agent

Минимальный агент, который пишет код по просьбе пользователя, и скил «спрашивай, а не додумывай». Со скилом агент не пишет код, пока не уточнит важные детали, и при этом не задаёт лишних вопросов. Насколько скил помогает, проверяем автоматически на наборе тест-кейсов и на разных моделях.

Документация в [docs/](docs/README.md), начинать с [docs/architecture.md](docs/architecture.md).

Первая версия документации лежит в ветке `archive/v1-docs` в папке `deprecated/`.
